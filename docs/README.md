## Найкоротший підсумок

**Запуск** (backend обов'язково першим):
```bash
cd backend     && npm run start:dev   # :3901
cd ai-reporter && npm run dev         # :3902
cd frontend    && npm run dev         # :3900
```
База — Homebrew Postgres на 5432. **`docker compose up` не запускати** — там порожня база.

**Стан даних:** 4 джерела з 7 справні. Не працюють: USD/CNH (нуль), Myfxbook sentiment (підмінено на COT), KNN-модель (не той шлях). Найбільше постраждали **AUD/USD і NZD/USD**.

**Не забути:** файл `links` у корені містить пароль від Myfxbook відкритим текстом — варто перевипустити ключі.
